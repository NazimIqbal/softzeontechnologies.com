## Free GitHub Pages deployment
1. Create a public GitHub repository named `softzeon-website`.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/softzeon-website/`

After deployment, replace YOUR-USERNAME in robots.txt and sitemap.xml with your actual GitHub username.

A custom domain such as `www.softzeon.com` is not free domain registration; you need to own/control that domain and configure it in GitHub Pages.
